# AGENTS.md

## Required approval before edits

For any task that may require modifying code or project files:

1. First inspect the relevant files if needed.
2. Explain the proposed implementation plan in detail.
3. List the files you expect to modify.
4. Wait for my explicit approval before making changes.

Until approval is given, do not:
- edit files
- create new files
- delete files
- run formatters that rewrite files
- apply patches
- commit changes

Read-only exploration is allowed.
